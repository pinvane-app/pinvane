# 도움 · 업데이트 · 문제 알리기

[English](../en/help.md) · [사용 방법 처음](../../README.ko.md)

도면을 넘기지 않고 받는 도움. Pinvane에는 오류 자동 보고가 없습니다.

## 문제 알리기

1. 보고서 만들기: Pinvane 의 **도움말 → 문제 알리기…**, 또는 `pinvane report-bug --steps "내가 한 일" --out report.txt` (AI 앱은 `make_bug_report` 를 부를 수 있음).
2. Pinvane이 자동으로 채우는 부분에는 앱 판 · 자료 형식 · 빌드 · 운영체제 · 창 브라우저 · 화면 언어 · 요금제 · 고정 오류 코드와 모듈 · 줄 · 횟수만 넣습니다. 이름 · 파일 경로 · 키 · 도면 내용은 자동 수집 항목에 없습니다. 재현 순서는 사용자가 적어 아래에 붙습니다.
3. 직접 적거나 고친 글은 보고서에 들어가므로 **전체를 읽어 보고**, 보내고 싶지 않은 줄은 지웁니다.
4. 직접 보냅니다(**복사** · **내 메일로 열기** · 파일 저장): [이슈](https://github.com/pinvane-app/pinvane/issues/new/choose)를 열거나 support@pinvane.com 으로. Pinvane은 지원 서버로 보내지 않습니다. AI 앱이 MCP 로 만들면 보고서 내용이 연결한 AI 앱에도 전달됩니다.

보고서가 없다면: Pinvane 판(`pinvane version`), Windows 판, 한 일, 일어난 일, 오류 문장을 적어 주세요 — 보이고 싶지 않은 이름 · 경로는 지우고.

**도면 · 프로젝트 파일 · 고객 이름 · 파일 경로는 절대 올리지 마세요.** 문제를 보여 줘야 하면 부품 몇 개만 넣은 작은 견본 프로젝트로 같은 일이 일어나게 해 주세요.

## 업데이트 확인

- Pinvane 의 **도움말 → 업데이트 확인** 또는 `pinvane update --check` 는 pinvane.com 에서 서명된 공개 업데이트 파일 하나를 받아 **내 컴퓨터에서** 판을 비교합니다. 요청에 앱 판 번호 · 사용권 · 기기 식별자 · 프로젝트를 넣지 않습니다. Pinvane은 앱에 든 공개 키로 서명을 확인한 뒤에만 업데이트 정보를 보여 줍니다.
- 접속을 처리하는 서버는 IP 주소 · 시각 · 요청 경로를 처리합니다.
- Pinvane은 요청할 때만 확인합니다(앱 시작 · 일정에 따른 자동 확인 없음). 업데이트 정보만 확인하며, 설치 파일을 자동으로 내려받거나 설치하지 않습니다.
- 판마다 바뀐 내용: [CHANGELOG.ko.md](../../CHANGELOG.ko.md) · https://pinvane.com/ko/changelog/.

## 자주 묻는 것

**배선도를 그려 본 적이 없습니다. 써도 되나요?**
네, 바로 그런 분을 위한 도구입니다. AI에게 부품과 할 일을 주면 AI가 Pinvane으로 그리고, 확인 목록이 아직 모르는 것을 쉬운 말로 묻습니다. 다만 만들기 전에 기계를 아는 사람이 길이 · 접점 · 단자를 확인해야 합니다.

**어떤 AI가 Pinvane을 쓸 수 있나요?**
로컬 MCP를 지원하는 AI 앱, 또는 명령을 실행할 수 있는 AI입니다. 우리는 Claude와 Codex로 시험합니다. Anthropic · OpenAI · Google의 내 API 키로 내장 AI 창을 쓸 수도 있습니다.

**AI 없이 손으로만 그릴 수 있나요?**
네. 편집기에 손으로 그리는 데 필요한 것이 다 있습니다: 부품 · 선 · 다발 · 글 · 표제란 · 용지 · 검사 · 내보내기.

**Pinvane이 내 도면을 어딘가로 보내나요?**
보통의 그리기 · 편집 · 내보내기에서는 보내지 않습니다. AI 기능을 쓰면 요청과 설계 정보가 내가 고른 AI 회사로 가고, 휴대폰 보기는 로컬 네트워크의 기기에 도면을 보여 줍니다. 나갈 수 있는 것은 [개인정보](https://pinvane.com/ko/privacy/)에 모두 적었습니다.

**어떤 파일로 내보낼 수 있나요?**
도면은 PDF · SVG · PNG · DXF, 작업표는 HTML · CSV · 엑셀 · PDF.

**인터넷 없이 되나요?**
그리기와 내보내기는 인터넷 없이 됩니다. 자동 사용권 확인은 하루 한 번 이하이고, 이용권 기간 안에서 인터넷 없이 최대 30일, 이용권이 끝난 뒤나 확인 기한 뒤에는 7일 마무리 기간이 있습니다. AI 서비스에는 연결이 필요합니다.

**구독인가요?**
아닙니다. Pro는 한 번 결제하는 30일 · 1년 이용권입니다 — 저절로 갱신되지 않고, 끝나도 다시 청구되지 않으며, 해지할 것도 없습니다. 다시 사면 새 이용권이 남은 기간 끝에 이어 붙습니다. 팀 이용권은 좌석마다입니다. 무료 요금제는 기간 제한이 없고 AI 기능이 없습니다. 14일 동안 모든 기능을 무료로 써 볼 수 있습니다 — 카드 없이. 이용권은 판매가 열리면 살 수 있습니다 — 요금: https://pinvane.com/ko/pricing/.

**이용권이 끝나면 어떻게 되나요?**
이용권이 끝나기 7일 전과 1일 전에 앱이 알려 줍니다. 끝난 뒤 7일 동안은 모든 기능을 그대로 써서 하던 일을 마칠 수 있습니다. 그 뒤에도 도면 열기 · 보기 · 내보내기는 됩니다(내보낸 파일에 표시가 붙을 수 있음). 이용권을 다시 사면(남은 기간 끝에 이어 붙고, 저절로 갱신되지는 않습니다) 편집과 AI를 다시 쓰고, 무료로 옮기면 무료 한도 안에서 편집할 수 있습니다(AI 없음).

**어떤 용지 크기를 쓰나요?**
A4 · A3 · A2 · A1 · A0과 사용자 크기, 세로 · 가로, 고칠 수 있는 표제란.
